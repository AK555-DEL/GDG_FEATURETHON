# GDG Featureathon

Welcome to the GDG Featureathon project hub. This repository brings together five existing open-source projects and beginner-friendly setup guides so you can get started quickly and spend more time building features.

Each project remains in its original GitHub repository. This central repository contains links and documentation only; it does not include copies of the project source code.

## Participant instructions

1. Choose one project and open its setup guide above.
2. Read the prerequisites before installing anything. The projects use different package managers, runtimes, and optional services.
3. Use PowerShell commands in the guides where provided. Docker is optional unless you choose the Docker-based setup for myDrive.
4. Clone the selected original repository and follow its README if it has newer or more detailed instructions.
5. Run the documented test or build checks before submitting a change.

You only need to install the tools required by your chosen project. Do not copy source code into this hub or commit passwords, API keys, or local environment files.

## Contributing

### Improving this project hub

1. Fork this central repository and create a branch for your documentation change.
2. Keep the setup guides consistent with the linked project's current README and configuration.
3. Check all relative links and command snippets before opening a pull request.
4. Open a pull request describing the participant problem your change solves.

### Contributing a feature to a selected project

Feature code belongs in that project's original repository, not in this documentation hub. Check the project's contribution guidelines and license, then follow its process for a fork, branch, tests, and pull request. You may need permission to contribute to the original repository.

## Documentation sources

Setup commands and requirements were checked against each linked project's README and repository configuration when these guides were prepared. Project maintainers may change those instructions; if the upstream README differs, follow the upstream instructions and report the discrepancy so this guide can be updated.
